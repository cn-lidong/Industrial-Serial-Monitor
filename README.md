五、典型使用场景
场景1：PLC 调试
接入 PLC 串口 → Modbus RTU 读取寄存器 → 实时曲线显示数据变化
场景2：多设备产线监控
添加多个串口 → 配置轮询任务 → 自动采集所有设备数据 → MQTT 上云
场景3：传感器数据采集
串口接入传感器 → 解析数据 → 日志记录 → 触发词报警（异常时提示）
场景4：车载 CAN 诊断
连接 CAN 总线 → 查看 CAN 帧 → CANopen 解析 SDO/PDO → 定位故障节点
场景5：自动化测试
编写 Python 脚本 → 定时发送指令 → 接收并校验响应 → 自动记录结果
